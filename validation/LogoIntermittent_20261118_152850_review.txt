0x0A Logo 간헐 고장 실물 확인 — 2026-11-18

대상: Serial 26J07-0021 / InitNumber 0x4729D1C4 / J-Link 69653815.
실행 App: 납품/CJ_Git_20261111의 CJ_App.bin과 Flash 전체 바이트 일치.
현재 CJ_Git_20261116 BIN과는 다름. 펌웨어를 변경하지 않고 현재 연결된 제품을 조사함.

방법
- GUI 조작 없이 J-Link로 실행 중 RAM/Flash 읽기.
- LIN으로 0x0A Logo만 낮은 밝기 제어. 다른 의자/다른 구역 제어 없음.
- Reset/Halt/다운로드/코드 수정/Flash 또는 RAM 강제 쓰기 없음.
- 자동검사 모드를 시작하지 않아 기존 100ms 진단 및 2초 확인 동작 유지.

확인 결과
1. 최초 소등 상태 60초: Logo 24개 ACTIVE, 고장 없음.
2. RGB 각 4.7%, 흰색 4.7% 및 2% 포함 118초: 고장 없음.
   명령 후 전체 진단 갱신을 기다린 샘플에서 24개 LED PWM 읽기와 쓰기 목표 모두 일치.
3. 흰색 RGB=(26,26,26), 약 10.2% 명령 후 약 0.19초에 LED 13 저전압 검출.
   status=0x81: ACTIVE + UV_FLAG. ledStatus=0x00: Open/Short 기록 없음.
   이 순간 LED 13의 read PWM=(3340,3340,3340), write PWM=(3340,3340,3340).
   보드 voltageFault=0, OSP 통신/CRC/Manchester 오류 카운터 모두 0.
4. 최초 고장 발견 직후 시험 스크립트가 Logo OFF를 전송하고 반복 점등을 중단함.
   이후 기존 순차 진단에서 저전압 기록이 확인된 노드: 5, 13, 15, 16, 17, 18, 20, 22, 23, 24.
   이 기록이 순차로 나타난 시간을 각 LED의 실제 고장 시작 시각으로 해석하면 안 됨.
5. OFF 후 약 4.0초에 모든 캐시 진단값 정상 복귀. 마지막 PWM=0, 24개 ACTIVE.

해석 및 한계
- 단순 진단 갱신 공백과 별도로, LED가 보고한 저전압 플래그가 실제로 검출됨.
- 소프트웨어에 온도/Open/Short/통신 고장 증거는 없었음.
- 보드 전원 진단 정상은 Logo 모듈까지의 전원 전압을 직접 측정했다는 뜻이 아님.
- Logo의 5V/GND 커넥터, 하네스, 전원 공급부 및 모듈 VDD 파형을 우선 확인할 근거가 있음.
- 특정 LED 13만의 불량이나 특정 커넥터/레귤레이터 불량으로는 확정할 수 없음.
- 고장 순간 status는 ACTIVE이며 setup=0x24(UV_FSAVE=0)이므로,
  저전압 플래그 때문에 자동 SLEEP에 들어갔다고 설명할 수 없음.
- 눈으로 실제 소등을 확인한 시험은 아님. 고장 발견 후 소등은 시험 스크립트가 명령함.
- 아날로그 전압 파형은 계측하지 않아, 사용자가 보았던 미점등의 직접 원인까지 확정하지 않음.
